Eleutheria, versione 3.10a a 32 bit (beta).

Tutte le novità, al solito, sono elencate in whatsnew.txt.

Il formato dei file di export è spiegato in export.txt, ed ha subito, in
questa versione, alcune variazioni.

Il supporto multimud - ora completamente funzionante - è documentato in
multimud.txt.

Per l'installazione, se il vostro file di partenza si chiama
Eleutheria.zip, scompattatelo in una directory temporanea ed eseguite il
file setup.exe.
Se invece si chiama EleutheriaNoSetup.zip, scompattatelo nella directory in
cui intendete porre Eleutheria, facendo attenzione a mantenere i nomi delle
sottodirectory (checkbox 'Use Folder Names' in Winzip, opzione -d in
pkunzip, comportamento di default in unzip), e create un collegamento al
file Eleutheria.exe.
In ogni caso vi consiglio, prima di procedere all'installazione della nuova
versione, di cancellare completamente quella precedente.

Il file da associare eventualmente alle estensioni .wld, .obj, .mob, .shp,
.zon e .ele è Eleutheria.exe.

Potete scaricare le nuove versioni del programma dalla mia homepage
(http://www.netforward.com/poboxes/?lavinio); per qualsiasi problema,
scrivetemi all'indirizzo lavinio@poboxes.com.
